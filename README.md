# CHERI-Tag-Controller
This repository houses all files relevant to my Part II Project for the Computer Science Tripos.

# Legal
The Tag Controller Simulator program interfaces with ChampSim, the open-source trace-based cache
simulator (https://github.com/ChampSim/ChampSim), which is released under the
Apache-2.0 licence. As required by the licence, I declare here that modification
of ChampSim is required for all parts of the software in this repository to work correctly. Specifically, `/setup.sh` performs this modification to the ChampSim repository after cloning it.

\section*{Original Aims of the Project}

To develop a framework in which a computer architect can implement and evaluate the
algorithms of a memory access controller for use in the microarchitecture of a
tagged memory architecture. To also use the framework to evaluate two existing
tag controller implementations.

\section*{Work Completed}

I successfully developed the framework, and used it to evaluate two existing tag
controller implementations. I also developed an additional visualisation tool
allowing insight into the workings of the tag controllers to be gained visually.
I then used these tools to develop a novel tag controller of my own design,
which I evaluated and compared to the existing ones.

1. Please write 100 words on your current project ideas.

Tagged memory implementations that use a tag table require a hardware tag controller to fetch both the value from main memory and the tag information from the table. Several existing controllers use different algorithms/schemes to store tags in the table.
As a core objective, I aim to develop a tag controller simulator that can be used to evaluate two existing algorithms for tag table storage. The simulator should be able to determine the memory access patterns of the simulated tag controller for different workloads, and how these would translate to DRAM accesses if employed in a given memory hierarchy.
As an additional objective, I aim to develop an analysis engine that will monitor the access patterns and look for patterns that lend themselves to compression and optimisation opportunities, suggesting these to the user of the engine.
As an additional objective, I aim to develop a novel algorithm for tag table storage.
As an additional objective, I aim to implement my algorithm in hardware, using a hardware description language, and verify its correctness.
